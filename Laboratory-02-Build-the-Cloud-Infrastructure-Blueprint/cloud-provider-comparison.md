## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.
AWS offers more variety since it was the first in the market. As such, it has build up a massive assortments of tools and features that cover any and all situations.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?
I'd recommend Microsoft Azure as it is specifically tailored to synergize with Microsoft tools and products. It is also cost-effective for companies already using Microsoft software as it does not conflict with licensing.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?
Google Cloud Platform is better for this as Kubernetes are build by Google themselves. Kubernetes relies heavily on advanced data parsing for Google search and YouTube so GCP is the clear choice.

### 4. What similarities did you observe among the three cloud providers?
At their core, all three provide the exact same basics: virtual computers, online hard drives, secure private networks, and user access controls. They also all use a flexible pay-as-you-go pricing model instead of forcing you to buy physical hardware.
