# Cloud Infrastructure Components
---
## 1. Compute Resources
* **Description:** Compute resources are the CPU and RAM used to execute programs and process data.
* **Importance:** They allow organizations to scale processing power up or down on-demand without buying physical hardware.
* **In KillerCoda:** This is represented by 1 vCPU and 1.86 GB of RAM provided by the virtual machine.

---

## 2. Storage Resources
* **Description:** Storage resources provide persistent or temporary space to save files and data.
* **Importance:** Reliable storage ensures data security and rapid read/write access for applications.
* **In KillerCoda:** This is shown by the 19 GB root disk and RAM mounts.

---

## 3. Networking Resources
* **Description:** Networking components create communication pathways between virtual machines, internal networks, and the internet.
* **Importance:** They enable multi-tier application connectivity, traffic management, and secure isolation .
* **In KillerCoda:** This is represented by the IP 172.30.1.2 allowing for internet connection.

---

## 4. Operating System
* **Description:** The operating system is the software layer that manages hardware and provides an environment for apps to run.
* **Importance:** A standardized OS ensures consistent application deployment and secure resource isolation .
* **In KillerCoda:** This is represented by the Ubuntu 24.04.4 LTS operating system  .
