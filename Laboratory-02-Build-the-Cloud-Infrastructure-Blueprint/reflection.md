# Mission Reflection

---

This laboratory activity has made me more aware of the different components and inner workings of a cloud server. I've never made an effort into understanding how fascinating cloud computing actually is.

First, computing resources stand out as the most critical component in a cloud computer. Without computing power, the other components seem useless at worst, and inefficient at best. Having the biggest and fastest storage and the fastest internet in the world but if your computing power is slow, it bottlenecks the system so much that the other components' quality or quantity hardly matter.

Linux is lightweight, stable and more importantly, open-source. It gives the environment an edge when it comes to cloud computing. 

Maintaining a clean and thorough documentation provides structure for system maintenance. It outlines system architecture, software dependencies, and default configurations; preventing misconfigurations, reducing deployment errors and serves as a "history" for future troubleshooting.

Throughout this mission, I developed several practical new skills. These include inspecting and extracting hardware parameters via the Linux command line, translating physical machine specifications into abstracted cloud resources, outlining my own cloud architecture and how they flow into each other.

Finally, completing this mission significantly enhances my GitHub portfolio. By organizing structured reports, infrastructure analysis, and configuration walkthroughs into a repository, my profile now effectively demonstrates hands-on technical competence in systems administration.
