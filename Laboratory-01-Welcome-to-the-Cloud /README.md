# Laboratory 01: Welcome to the Cloud

## Mission Overview
### Congratulations!
You have been accepted as a Junior Cloud Infrastructure Engineer Trainee at CloudNova Technologies, a
company specializing in cloud infrastructure, virtualization, and enterprise cloud solutions.
As part of your onboarding process, you must complete your first mission. Before deploying cloud services or
managing enterprise infrastructures, every cloud engineer must first learn how to work inside a Linux
environment, document their work professionally, and maintain a version-controlled portfolio using GitHub.
Your task is to complete the onboarding mission using the KillerCoda Playground and create your personal
Cloud Computing Portfolio on GitHub. This portfolio will serve as your professional workspace throughout the
semester and will be updated after every laboratory activity.
Complete each checkpoint carefully. Every completed task represents a real-world responsibility of a cloud
engineer. 

## Objectives
* Access a cloud-based Linux environment using KillerCoda.
* Explore and navigate the Linux operating system.
* Gather basic system information.
* Organize files and directories using Linux commands.
* Create and maintain a professional GitHub repository.
* Document technical work using Markdown.
* Demonstrate proper documentation practices used by cloud professionals.

## Activities Performed
* Launched a Linux Playground instance running Ubuntu on KillerCoda.
* Created a custom user account (`rbvergara`), assigned a password, and logged into the newly created user.
* Inspected the Linux distribution, kernel version, CPU architecture, memory allocation, and available disk space.
* Created structured directories (`Documents`, `Notes`, `Reports`, and `Screenshots`) inside the home directory.
* Recorded system configuration details and mission steps into Markdown files (`system-information.md`, `about-me.md`, and this `README.md`).
* Created a public GitHub repository
* Created the required folder structure
* Uploaded all required files and screenshots to GitHub
## Linux Commands Used
* `useradd` - Created the new system user account with a home directory and bash shell.
* `passwd` - Set a secure password for the new user.
* `usermod` - Modified user group memberships to grant `sudo` privileges.
* `su` - Switched user sessions.
* `whoami` - Displayed the current active username.
* `pwd` - Printed the current working directory path.
* `hostname` - Displayed the network hostname of the system.
* `cat` - Read files and used heredocs to write content into Markdown files.
* `uname` - Displayed system and kernel version information.
* `lscpu` - Displayed detailed CPU architecture information.
* `free` - Checked total and available system memory.
* `df` - Displayed available disk space across filesystems.
* `mkdir` - Created new directories for workspace organization.

## Skills Learned
* Navigating and verifying cloud-based Linux terminals.
* Managing users, groups, and permissions securely via command line.
* Querying hardware and OS metrics for system health diagnostics.
* Structuring directory hierarchies for technical projects.
* Utilizing Markdown for clean, professional engineering documentation.
