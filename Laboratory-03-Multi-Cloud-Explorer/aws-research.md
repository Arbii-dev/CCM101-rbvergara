# Amazon Web Services (AWS) Research

### Brief Overview
Amazon Web Services (AWS) is a massive cloud platform launched in 2006 that provides over 200 on-demand services.

### Global Infrastructure
The network relies on physically separated regions and multiple availability zones to guarantee availability.

### Cloud Management Console
Admins interact with the environment via the AWS Management Console dashboard and command-line interface tools.

### Four (4) Core Services
1. **Amazon Elastic Compute Cloud (EC2):** for virtual compute power.
2. **Amazon Simple Storage Service (S3):** for scalable object storage.
3. **Amazon Relational Database Service (RDS):** for managed relational SQL databases.
4. **Amazon Virtual Private Cloud (VPC):** for isolated network segregation.

### Three (3) Advantages
1. **Unmatched market maturity** 
2. **Vast global partner network** 
3. **Enterprise grade security and compliance:**
   
### Typical Enterprise Use Cases
Common implementations inveolve modernizing enterprise software, organizing massive data lakes and deploying multi-region disaster recovery systems.
