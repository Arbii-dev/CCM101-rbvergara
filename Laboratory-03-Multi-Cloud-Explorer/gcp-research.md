
# Google Cloud Platform (GCP) Research

## Brief Overview
Google Cloud Platform uses the exact same framework that powers Google search and YouTube, with emphasis on data and AI capabilities.

### Global Infrastructure
Infrastructure centers are on an advanced software-defined network backed by a private global fiber-optic backbone that minimizes reliance on public internet.

##$ Cloud Management Console
Management is executed through the Google Cloud Console, the gcloud command-line SDK, and browser-based Cloud Shell environments.

### Four (4) Core Services
1. **Google Compute Engine (GCE):** for virtual machines.
2. **Google Kubernetes Engine (GKE):** for container orchestration.
3. **BigQuery:** for rapid enterprise analytics.
4. **Cloud Storage:** for online cloud storage.
   
### Three (3) Advantages
1. **Industry-leading data analytics and AI/ML leadership.** 
2. **Pioneered container orchestration (Kubernetes).** 
3. **Ultra low latency private networking.** 

### Typical Enterprise Use Cases
Common enterprise deployments target real-time streaming data pipelines, heavy machine learning model training, and scalable containerized microservices architectures.
