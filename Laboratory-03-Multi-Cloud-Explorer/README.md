# Linux Server Investigation

* **Operating System:** Ubuntu 24.04.4 LTS (Noble Numbat)
* **CPU:** 1 vCPU (Intel Xeon E312xx @ 2.00GHz)
* **Memory (RAM):** 1.9 GB total (~1.5 GB available)
