| Category | Amazon Web Services (AWS) | Microsoft Azure | Google Cloud Platform (GCP) |
| :--- | :--- | :--- | :--- |
| **Launch Year** | 2006 | 2010 | 2008 |
| **Compute Service** | Amazon EC2 | Azure Virtual Machines | Google Compute Engine |
| **Storage Service** | Amazon S3 | Azure Blob Storage | Cloud Storage |
| **Networking Service** | Amazon VPC | Azure Virtual Network | Google Cloud VPC |
| **Identity Service** | AWS Identity and Access Management | Microsoft Entra ID | Cloud Identity |
| **Primary Strength** | Longest market experience and deeper services| Seamless hybrid cloud integration and native corporate Windows/.NET compatibility | Industry-leading data analytics, AI/ML leadership, and container orchestration |
| **Ideal Organizations** | Large enterprises requiring custom, flexible architectures and maximum service variety | Corporations deeply invested in Microsoft infrastructure | Data-driven tech companies, AI developers, and cloud-native organizations leveraging Kubernetes |

## Reflection Questions

### 1. Which cloud provider offers the broadest range of services?
Amazon Web Services (AWS) offers the broadest range of services, featuring over 200 fully featured options. Because it launched first in 2006, it has had the most time to build tools for almost any technical need.

### 2. Which provider best integrates with Microsoft technologies?
Microsoft Azure offers the best integration with Microsoft technologies like Windows Server, Active Directory, and .NET apps. Companies can easily stretch their local office servers into the cloud and manage user logins using Microsoft Entra ID.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?
Google Cloud Platform (GCP) leads in Artificial Intelligence and Kubernetes. Google originally created Kubernetes, making Google Kubernetes Engine (GKE) the top container platform, and provides advanced AI tools like Vertex AI.

### 4. Which cloud platform would you personally choose and why?
Google Cloud Platform (GCP) would be the choice for its powerful data analytics tools and high-speed private fiber network. Its reliable developer tools and focus on container systems fit well with modern software development.
