
# Microsoft Azure Research

### Brief Overview
Microsoft Azure is an enterprise grade cloud ecosystem released in 2010 that natively bridges traditional windows server enviroments with modern cloud applications.

### Global Infrastructure
Spans more than 60 geographic regions worldwide, utilizing paired regional setups to steamline data replication and recovery protocols.

### Cloud Management Console
Controls are handled through the web based Azure Portal, role based access control policies and Azure CLI/Powershell automation.

### Four (4) Core Services
1. **Azure Virtual Machines (VMs):** for computing
2. **Azure Blob Storage:** for unstructured data files.
3. **Azure SQL Database:** for managed relational data.
4. **Microsoft Entra ID (formerly Azure Active Directory):** for identity management.

### Three (3) Advantages
1. **Seamless hybrid cloud integration via Azure Arc.**
2. **Native integration with Microsoft software licences.**
3. **Unified Security and Governance.** 

### Typical Enterprise Use Cases
Organizations use it to stretch on-premises networks into the cloud, manage corporate single sign-on security, and run massive data warehousing.
